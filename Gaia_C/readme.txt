# Gaia Conscious Certification System

## Project overview

The Gaia Conscious Certification System is being
developed to support the management of certification
applications, assessments, decisions and certified clients.

## Development approach

The system will be developed in phases according to
GC-BUILD-INSTR-001.

## Existing frontend

The initial frontend prototype includes:

- Public website
- Login and registration pages
- Client dashboard
- Scheme selection
- Application page

## Development phases

- Phase 0: Planning and setup
- Phase 1: Foundation and client portal
- Phase 2: Application and assessment preparation
- Phase 3: Assessment and certification decisions
- Phase 4: Certificates and ongoing compliance
- Phase 5: Governance and additional functions
- Phase 6: Testing and launch

## Current status

Phase 0 - Planning and repository setup.

## Important note

The existing frontend is a prototype.
Backend functionality, database integration,
authentication and permissions still need to be implemented.
